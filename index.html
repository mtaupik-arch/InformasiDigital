☁️ Integrasi Google Drive

Status & Konfigurasi

Semua gambar, audio, video, PDF (logo, foto profil, lampiran soal ujian, dsb.) diunggah ke folder Google Drive sekolah jika integrasi aktif. Jika nonaktif / gagal, sistem memakai Supabase Storage sebagai cadangan.

—

Panduan singkat

  1. Buat project di Google Cloud Console → aktifkan Google Drive API.
  2. Buat Service Account → unduh JSON key.
  3. Di Google Drive, buat folder (mis. SIS-Media) → Share ke email service account (Editor).
  4. Salin Folder ID dari URL folder (.../folders/ID_INI).
  5. Tempel Folder ID + JSON di form atas → Simpan → Tes Koneksi.

File terunggah (indeks)

100 file terakhir yang tercatat di database setelah upload ke Drive.
